# Security Policy

## Reporting a Vulnerability

Please report security issues privately.

- Contact: tradergunny@gmail.com
- Provide steps to reproduce and impact analysis

## Scope

- Content script injection and DOM interaction
- PII detection engine behavior
- Storage handling for settings and events
- Any analytics or telemetry pipeline

## Out of Scope

- Third-party platform vulnerabilities (ChatGPT, Claude)
- User device compromises
