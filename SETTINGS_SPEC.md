# Settings Spec

## Sections

- Detection
- Notifications
- Privacy
- About

## Controls

- Category toggles for each PII type
- Sensitivity slider: Relaxed, Standard, Strict
- Submit blocking toggle for Critical/High
- Analytics opt-in toggle
- Clear local data button
- Reset to defaults with confirmation

## Storage

- Persist settings with `chrome.storage.sync`
- Changes apply immediately without reload

## UX Requirements

- Accessible labels and keyboard navigation
- Clear descriptions for each toggle
- Immediate feedback on changes
