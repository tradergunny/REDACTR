# Privacy Policy

**Effective Date:** 2026-02-16

## Summary

REDACTR is a browser extension that detects potential PII in prompts before submission. All detection runs locally in your browser. Prompt text and detected PII are never transmitted or stored.

## Data We Process

- Prompt text: processed in-memory only, never stored
- Detection metadata: stored locally for dashboard analytics
- Settings and allowlist: stored via Chrome storage sync/local

## Data We Do Not Collect

- Prompt content
- Detected PII strings
- Browsing history beyond supported sites

## Analytics

- External telemetry is opt-in only
- When enabled, only anonymous event metadata is sent
- No prompt content or PII is ever transmitted

## Data Retention

- Event metadata: rolling 30 days (user can clear)
- Settings and allowlist: until user deletes

## Data Sharing

- We do not sell or share personal data

## Security

- Local-only processing
- Chrome encrypted storage for local data
