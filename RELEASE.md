# Release Process

## Build

1. Install dependencies
2. Run production build
3. Verify output bundle

## Package

- Create a signed extension package
- Verify manifest permissions
- Run smoke tests on ChatGPT and Claude

## Chrome Web Store

- Upload package
- Provide privacy policy
- Submit listing assets

## Versioning

- Update version in manifest
- Update `CHANGELOG.md`

## Release Checklist

- All tests pass
- No new permissions
- Performance targets met
- Privacy policy updated
